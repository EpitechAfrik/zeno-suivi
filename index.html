      Quand on finit

      L'unité est le jour de boucle humaine : Claude Code écrit le code, la ressource relit la spec, répond aux questions et recette. Chaque demande ouverte porte une charge restante dans cette unité, chaque ressource une capacité hebdomadaire. Les demandes affectées sont enchaînées par ressource (en cours d'abord, puis par priorité et par phase) ; ce qui n'a pas de ressource n'est pas daté. Calibrage mesuré sur l'historique : 2 000 lignes V2 revues par jour de boucle, compaction V1 → V2 de 3,5, une demi-journée de recette par module.
